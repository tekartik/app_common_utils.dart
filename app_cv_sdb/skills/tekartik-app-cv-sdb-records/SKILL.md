# cv records in sdb (tekartik_app_cv_sdb)

`tekartik_app_cv_sdb` binds `package:cv` models to `idb_shim`'s sdb
("simple db", an IndexedDB shaped API with versioned schemas, object stores
and indexes) so stores are typed by a record class: an `ScvRecord` is a
`CvModel` that knows its `SdbRecordRef`, an `ScvStoreRef<K, V>` wraps an
`SdbStoreRef<K, Map<String, Object?>>`. Same code in the browser
(IndexedDB), on the VM (sembast based `sdbFactoryIo`) and in memory.

## Guidelines

* Dependency (git, not on pub.dev):
  ```yaml
  dependencies:
    tekartik_app_cv_sdb:
      git:
        url: https://github.com/tekartik/app_common_utils.dart
        path: app_cv_sdb
    cv: ^1.1.6
    idb_shim: ^2.9.5
  ```
* One import: `package:tekartik_app_cv_sdb/app_cv_sdb.dart` re-exports
  `package:cv/cv.dart` and `package:idb_shim/sdb/sdb.dart` (`SdbDatabase`,
  `SdbFactory`, `SdbOpenDatabaseOptions`, `SdbDatabaseSchema`, `SdbFilter`,
  `SdbBoundaries`, `SdbFindOptions`, `SdbTransactionMode`, `SdbTimestamp`,
  `SdbBlob`, `newSdbFactoryMemory`, `sdbFactoryMemory`, `sdbFactoryIo`,
  `sdbFactoryWeb`, `kSdbDartIsWeb`...). For a per-app location on VM and
  web use `dockGetSdbFactory` from `tekartik_app_dock`.
* Records: extend `ScvIntRecordBase` (int keys) or `ScvStringRecordBase`
  (string keys), declare `final` `CvField`s and `List<CvField> get fields`;
  register with `cvAddConstructors([DbNote.new])` before any read
  (instances are built through `cvBuildModel`). Field values must be
  IndexedDB values: numbers, strings, bools, lists, maps,
  `CvField<SdbTimestamp>` (alias `ScvTimestamp`, `SdbTimestamp.now()`) and
  `CvField<SdbBlob>` (alias `ScvBlob`, bytes). `cvEncodedTimestampField`
  and `cvEncodedBlobField` are deprecated. Do not name a field `id`: it
  would shadow the `id` getter of the record (use `recId` and the key path
  `'id'`).
* Stores, top level finals: `scvIntStoreFactory.store<DbNote>('note')`
  (`ScvIntStoreRef<DbNote>` = `ScvStoreRef<int, DbNote>`),
  `scvStringStoreFactory.store<DbUser>('user')` or
  `scvStoreRef<String, DbUser>('user')`. `name`, `rawRef`, equality by
  name, `record(key)`, `records(keys)` (`List<ScvRecordRef>`),
  `index<I>(name)` (see the index skill), `cast<RK, RV>()`, `castV<RV>()`.
* Opening needs a version and a schema; stores and indexes can only be
  created during a version change. Declarative:
  `SdbOpenDatabaseOptions(version: 1, schema: SdbDatabaseSchema(stores:
  [noteStore.schema(autoIncrement: true, keyPath: ..., indexes: [...])]))`,
  idb_shim creates what is missing when the version increases (add stores
  to the list and bump `version`). Imperative: `onVersionChange: (event) {
  if (event.oldVersion < 1) { event.db.scvCreateStore(noteStore,
  autoIncrement: true); } }` (`ScvOpenDatabaseExt`, returns an
  `ScvOpenStoreRef` with `createIndex`). `await db.close()` when done;
  `factory.deleteDatabase(name)` to reset.
* Keys: with `autoIncrement: true` int keys are generated by `store.add`;
  with `keyPath: 'id'` the key is read from and written to the record
  field named `id` (the `add` helpers fill it, an explicit value in that
  field is used as the key). Without either, write with
  `store.record(key).put(db, record)` or through a record whose `ref` is
  set.
* On a `keyPath` store only `add` (store or record), `get`, `delete` and
  the queries work: `put` and `update` pass an explicit key, which
  IndexedDB rejects on an in-line key store (the transaction aborts with
  `DatabaseException: Aborted`). Use a plain `autoIncrement` store (no
  `keyPath`) for records that get updated in place.
* `ScvRecordRef<K, V>` (`key`, `store`, `rawRef`): `get(client)` (`V?`),
  `exists(client)`, `put(client, value)` (upsert, returns a clone of
  `value` carrying the ref, the argument is untouched), `add(client,
  value)` (same but throws `StateError` when the key exists),
  `delete(client)`, `onRecord(db)` (`Stream<V?>`). `ref.cv()` builds an
  empty `V` bound to the ref:
  `await (noteStore.record(1).cv()..title.v = 'x').put(db);`
* Record methods (the record needs a ref): `put(client)` upserts;
  `add(client)` returns `false` when its id exists, otherwise inserts
  (key generated by the store with `autoIncrement`, or taken from the key
  path field) and updates `id`; `update(client)` returns `false` when
  missing; `delete(client)` returns whether it existed. `hasId`, `id`,
  `idOrNull`, `ref`, `refOrNull`, `rawRef`, setters `id =`, `ref =`,
  `refOrNull =`, `idOrNull =`; `scvClone()` copies fields and ref.
* `store.add(client, record)` inserts with a generated (or key path) key
  and returns a new instance with the id; the argument keeps no id (unlike
  the sembast variant of this package).
* Store reads: `findRecords(client, {boundaries, filter, offset, limit,
  descending, options})`, `findRecord(...)` (first or `null`),
  `findRecordKeys(client, {options})`, `streamRecords(client, {options})`
  (one record at a time, for big stores), `count(client, {boundaries,
  offset, limit, descending, options})`, `delete(client, {boundaries,
  offset, limit, descending})`, `onRecords(db, {options})`
  (`Stream<List<V>>`: current content, then every change).
  `SdbBoundaries.values(lower, upper)`, `.lowerValue(k)`, `.upperValue(k)`,
  `.key(k)` range over primary keys (uses the index); `SdbFilter` is
  sembast's `Filter` (`SdbFilter.equals('field', v)`, `SdbFilter.and`...)
  and runs in memory on the fetched records; `SdbFindOptions(boundaries:,
  filter:, limit:, offset:, descending:)` groups them.
* Lists: `Iterable<ScvRecordRef>.getObjects(client)` (`List<V?>`) and
  `.delete(client)`; `List<ScvRecord>.put(client)` and `.delete(client)`
  (one transaction on the store of the first record); `records.ids`;
  `toMapById()` (int or string keyed) and `toMap()`.
* Transactions: every method takes an `SdbClient` (`SdbDatabase` or
  `SdbTransaction`); outside a transaction each call opens its own. Group
  writes with `noteStore.inTransaction(db, SdbTransactionMode.readWrite,
  (txn) async {...})` or across stores with
  `db.inScvStoresTransaction([storeA, storeB], mode, (txn) async {...})`
  and pass `txn` to every call inside. IndexedDB transactions commit as
  soon as no request is pending: never `await` timers, network calls or
  another database inside the callback.
* `toString()` on a record is `Record(store, key) {field: value}` (or
  `<null> {...}` without ref); `==` compares content only.
* Tests: `newSdbFactoryMemory().openDatabase('test', options: ...)` per
  test, `tearDown(() => db.close())`; run `dart test` on the VM and with
  `-p chrome`.

## Examples

### Model, schema and CRUD

```dart
import 'package:tekartik_app_cv_sdb/app_cv_sdb.dart';

class DbNote extends ScvIntRecordBase {
  final title = CvField<String>('title');
  final content = CvField<String>('content');
  final createdAt = CvField<SdbTimestamp>('createdAt');

  @override
  List<CvField> get fields => [title, content, createdAt];
}

final noteStore = scvIntStoreFactory.store<DbNote>('note');

final dbSchema = SdbDatabaseSchema(
  stores: [noteStore.schema(autoIncrement: true)],
);

Future<void> main() async {
  cvAddConstructors([DbNote.new]);
  var db = await newSdbFactoryMemory().openDatabase(
    'notes.db',
    options: SdbOpenDatabaseOptions(version: 1, schema: dbSchema),
  );

  // Generated key; the returned instance carries the id.
  var note = await noteStore.add(
    db,
    DbNote()
      ..title.v = 'First'
      ..createdAt.v = SdbTimestamp.now(),
  );
  print(note.id); // 1

  // Chosen key.
  await (noteStore.record(10).cv()..title.v = 'Tenth').put(db);

  // Read, modify, save.
  var read = (await noteStore.record(10).get(db))!;
  read.content.v = 'body';
  await read.put(db);

  // Key range (index) then in memory filter.
  var found = await noteStore.findRecords(
    db,
    boundaries: SdbBoundaries.lowerValue(5),
    filter: SdbFilter.equals(DbNote().title.name, 'Tenth'),
  );
  print(found.map((n) => n.id).toList()); // [10]
  print(await noteStore.count(db)); // 2

  print(await read.delete(db)); // true
  print(await noteStore.record(10).exists(db)); // false
  await db.close();
}
```

### Auto increment key stored in the record (keyPath)

```dart
import 'package:tekartik_app_cv_sdb/app_cv_sdb.dart';

/// The key also lives in the record (`id` field, keyPath) and is generated
/// by the store (autoIncrement). Such records are inserted and deleted, not
/// updated in place.
class DbEvent extends ScvIntRecordBase {
  final recId = CvField<int>('id');
  final name = CvField<String>('name');

  @override
  List<CvField> get fields => [recId, name];
}

final eventStore = scvIntStoreFactory.store<DbEvent>('event');

Future<SdbDatabase> openEvents(SdbFactory factory) => factory.openDatabase(
  'events.db',
  options: SdbOpenDatabaseOptions(
    version: 1,
    onVersionChange: (event) {
      if (event.oldVersion < 1) {
        event.db.scvCreateStore(eventStore, keyPath: 'id', autoIncrement: true);
      }
    },
  ),
);

Future<void> main() async {
  cvAddConstructors([DbEvent.new]);
  var db = await openEvents(newSdbFactoryMemory());

  // Generated key, copied into the `id` field of the returned instance.
  var started = await eventStore.add(db, DbEvent()..name.v = 'started');
  print('${started.id} ${started.recId.v}'); // 1 1

  // An explicit value in the key path field is used as the key.
  var custom = await eventStore.add(
    db,
    DbEvent()
      ..recId.v = 100
      ..name.v = 'custom',
  );
  print(custom.id); // 100
  print(await custom.add(db)); // false, key 100 exists

  var all = await eventStore.findRecords(db);
  print(all.toMapById().keys.toList()); // [1, 100]
  print((await eventStore.record(100).get(db))?.name.v); // custom

  print(await started.delete(db)); // true
  print(await eventStore.count(db)); // 1
  await db.close();
}
```

### Transactions over one or several stores

```dart
import 'package:tekartik_app_cv_sdb/app_cv_sdb.dart';

class DbAccount extends ScvStringRecordBase {
  final balance = CvField<int>('balance');

  @override
  List<CvField> get fields => [balance];
}

class DbTransfer extends ScvIntRecordBase {
  final from = CvField<String>('from');
  final to = CvField<String>('to');
  final amount = CvField<int>('amount');

  @override
  List<CvField> get fields => [from, to, amount];
}

final accountStore = scvStringStoreFactory.store<DbAccount>('account');
final transferStore = scvIntStoreFactory.store<DbTransfer>('transfer');

final bankSchema = SdbDatabaseSchema(
  stores: [accountStore.schema(), transferStore.schema(autoIncrement: true)],
);

/// Atomic move between two accounts plus a journal entry.
Future<void> transfer(SdbDatabase db, String from, String to, int amount) {
  return db.inScvStoresTransaction(
    [accountStore, transferStore],
    SdbTransactionMode.readWrite,
    (txn) async {
      var source =
          await accountStore.record(from).get(txn) ??
          accountStore.record(from).cv();
      var target =
          await accountStore.record(to).get(txn) ??
          accountStore.record(to).cv();
      source.balance.v = (source.balance.v ?? 0) - amount;
      target.balance.v = (target.balance.v ?? 0) + amount;
      await [source, target].put(txn);
      await transferStore.add(
        txn,
        DbTransfer()
          ..from.v = from
          ..to.v = to
          ..amount.v = amount,
      );
    },
  );
}

/// Single store transaction: reset every account.
Future<void> resetAccounts(SdbDatabase db) => accountStore.inTransaction(
  db,
  SdbTransactionMode.readWrite,
  (txn) async {
    var accounts = await accountStore.findRecords(txn);
    for (var account in accounts) {
      account.balance.v = 0;
    }
    await accounts.put(txn);
  },
);
```
